# Car-Sales-Dashboard
Designed an interactive Power BI dashboard to analyze car sales by region, category, and car type. Integrated data from Excel/SQL, enabled drilldowns, filters, and visuals for KPIs like revenue and sales trends, delivering actionable insights for decision-making.

Key Features:

Data Overview:
Total car sales, revenue, and units sold.
Year-over-Year (YoY) and Month-over-Month (MoM) growth analysis.
Top-performing regions, categories, and car types.

Filters and Drilldowns:
Filters for region, category, car type, time period, and sales channels.
Drilldown functionality to analyze trends at granular levels (e.g., region-wise breakdown by car type).

Visualizations:
Bar charts to show sales by category and car type.
Geographic heatmaps for region-wise performance.
Line charts for monthly/quarterly sales trends.
KPI cards for key metrics like total revenue, units sold, and profit margin.

Comparison Analysis:
Region-wise comparison of sales performance.
Category-specific analysis of SUVs, Sedans, Hatchbacks, etc.
Top-selling car models across different regions.

Insights & Alerts:
Automated alerts for underperforming regions or categories.
Insights into seasonal trends or peak sales periods.

Data Sources:
Sales Data:
Transaction-level data with fields like date, region, car category, car model, sales volume, and revenue.

Customer Demographics:
Age group, gender, and region-specific preferences.

Market Data:
External data on competitors or market share (if applicable).

Tools Used:
Power BI:
Data modeling, report creation, and interactive dashboard design.

Data Sources Integration:
Excel, SQL Server, or cloud services (e.g., Azure or Google Sheets) for importing data into Power BI.
ETL (Extract, Transform, Load):
Power Query for data cleaning and transformation.

Deliverables:
Interactive Power BI Dashboard:
Fully functional and accessible via desktop and mobile.

Documentation:
User guide for dashboard navigation and analysis.
Technical documentation for data sources, transformations, and visualizations.

Presentation:
Highlighting key findings and actionable recommendations based on the analysis.
